本版本为「存迹」0.3.0，接替 0.2.0；正式身份和用户数据目录保持不变。

0.3.0 更新

- 仅在 macOS 27 修正普通卡片色面和侧栏显示，保留原有窗口尺寸、布局、图标及其他系统的外观分支。
- 加入 Sparkle 应用内更新：默认手动检查，查看说明后下载、安装并重启；自动检查默认关闭。
- 补齐正式安装包中的日语资源，并校验三种语言、更新框架和签名配置。
- 修正附加 SMART 输出包含健康失败状态时可能被核心成功结果掩盖的问题。
- 更新与硬盘检测、测速、保存和导出互斥；退出会等待任务取消和清理完成。
- 已验证 macOS 27 隔离模拟升级和快照保留；没有 macOS 26 真机视觉验收，不承诺全系统效果完全相同。

0.2.0 没有更新器：旧用户需要手动安装本版一次，此后才能使用应用内更新。更新请求不上传硬盘信息和历史记录。

延续的 0.2.0 功能

- 正式 App 名称统一为“@APP_NAME@”，Bundle ID 保持 @BUNDLE_ID@。
- 保留原正式数据命名空间；首次启动会把内部 v2 中缺少的 SMART 快照和测速记录安全合并回来，不删除或改写 v2 源数据。
- 完善内置与本地外置硬盘识别、协议对应的 SMART 展示、读取完整性说明和只读安全校验。
- 优化顺序读写测速计时：缓冲区准备、界面进度更新与持久化确认不再混入吞吐率计时区间。
- 修正同一分钟内连续测速在趋势图中重叠、竖线或断裂的问题；每次真实测试现在都有独立顺序位置，并保留真实日期时间标签。
- 补齐关键指标的信息按钮与解释，改善历史筛选、导出与设置页排版。
- 原始 SMART JSON 默认脱敏；导出 JSON / CSV 前会明确提醒，因为用户主动导出的报告可能包含设备身份与健康元数据。
- 提供简体中文、英文和日文界面资源，正式包附带中英文安装、产品版权及版本说明。
- SHIXIN LAB 自有源码与文档采用 GPL-3.0-or-later 正式开源；官方名称、Logo、App 图标与品牌素材继续受独立商标及品牌政策保护。

已知边界

- 当前正式版通过 direct mode 读取核心 SMART / NVMe 数据，正常使用无需安装 Helper。
- 外置硬盘 SMART 取决于硬盘盒或转接芯片是否透传；读取不可用不等同于硬盘故障。
- 速度测试结果会受测试文件大小、可用空间、系统缓存、温度以及同时进行的渲染、复制等负载影响；比较性能时请保持测试条件一致。
- 当前安装包面向 Apple Silicon，最低支持 macOS @MINIMUM_OS@。
